Quiet

No protocol program is deployed, so no address can be derived as a burn pool: no coin has a recognised BURN destination today. What does run is the payout crank. Every hour it finds every coin whose split pays the protocol wallet and asks pump to distribute that coin's creator vault, and pump pays each row of the split; below pump's minimum it waits for the next hour.
